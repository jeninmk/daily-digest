# daily-digest

A personal, self-hosted morning digest. Answer a few questions about your interests
(news, sports, fashion, tech, finance), set a time, and get an email every morning
with articles to read and trending products in your markets.

Fork it, configure it, run it. No servers, no accounts, no domain required.
